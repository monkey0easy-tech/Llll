# Саше 50: музыкальный клип

Анимированный клип на песню к 50-летию Саши. Всё нарисовано кодом (Remotion + React + SVG), готовых картинок нет. Кадр 1920×1080, 30 fps, H.264.

## Быстрый старт

```bash
cd sasha50
npm install
# положите песню сюда:
cp /путь/к/song.mp3 assets/song.mp3
npm run dev        # Remotion Studio в браузере, можно смотреть и править
npm run render     # финальный рендер в out/sasha50.mp4
npm run render:test  # быстрый черновик в половинном размере (out/sasha50_test.mp4)
```

Длина клипа определяется по самой песне, плюс 5 секунд финального кадра с общей фотографией после конца музыки. Если `assets/song.mp3` нет, клип собирается без звука на 210 секунд.

## Фотографии

Кладите файлы в `public/photos/` с такими именами:

| Файлы | Что это | Где появляется |
|---|---|---|
| `child_01.jpg` … `child_10.jpg` | детство и школа | куплет 1, припев 1, мозаика (в сепии с зерном) |
| `youth_01.jpg` … | юность, институт, первая работа | припев 2, мозаика |
| `travel_01.jpg` … | поездки, страны, работа | куплет 2 (рядом с картой), припев 2, мозаика |
| `family_01.jpg` … | семья, дом | окна дома в куплете 3, мозаика |
| `friends_01.jpg` … | друзья, встречи | сундук с сокровищами в куплете 3, мозаика |
| `final_group.jpg` | общая фотография | последний кадр |

В каждой группе может быть от 0 до 10 файлов, подходят `.jpg`, `.jpeg`, `.png`, `.webp`. Порядок определяется номером в имени. Если фото не хватает, на его месте будет аккуратная рамка с надписью «фото скоро будет», так что рендер не упадёт.

После того как добавили или убрали фото, перезапустите `npm run dev` (или просто `npm run sync-audio`): список файлов пересобирается при запуске.

## Подгонка таймингов под песню

Все времена лежат в одном файле: `src/timings.ts`.

- `sections` задаёт начало и конец каждой сцены в секундах.
- `lines` задаёт каждую строчку текста: когда начинают её петь (`start`) и когда заканчивают (`end`). Если удалить `end`, он посчитается сам.

Как подогнать:

1. `npm run dev`, откройте композицию `Sasha50` и включите воспроизведение.
2. Когда начинается строчка, поставьте на паузу и посмотрите время (кадр ÷ 30 = секунда).
3. Впишите эту секунду в `start` нужной строчки, сохраните файл. Студия обновится сразу.
4. Когда расставите настоящие значения, поменяйте `SCALE_TO_SONG` на `false`. Пока там `true`, все примерные значения растягиваются пропорционально длине вашей песни.

Анимации привязаны к строчкам: если строчка «Тонкий, словно карандаш» сдвинется, карандаш-линейка сдвинется вместе с ней.

У каждой сцены есть своя композиция (`S0-Intro`, `S1-Verse1` … `S8-Finale`, `S9-Outro`) с нужным куском песни, чтобы проверять сцены по одной. `Lab-Characters` показывает лист со всеми персонажами.

## Рендер

```bash
npm run render
```

Готовый файл: `out/sasha50.mp4`. На обычном ноутбуке это занимает от 15 до 40 минут. Ускорить можно флагом `--concurrency`, например `npx remotion render Sasha50 out/sasha50.mp4 --concurrency=8`.

При первом запуске Remotion сам скачает свой Chrome. Если компьютер без интернета или скачивание не проходит, укажите любой установленный Chrome/Chromium:

```bash
REMOTION_CHROME=/путь/к/chrome npm run render
```

Шрифты (Rubik и Caveat с кириллицей) загружаются из Google Fonts во время рендера, поэтому интернет всё же нужен.

## Что где лежит

- `src/timings.ts`: все тайминги
- `src/scenes/`: сцены по порядку (`ChorusScene.tsx` общий для припевов 1 и 2)
- `src/components/Figure.tsx`: параметрический персонаж, из него собраны все герои
- `src/components/characters.ts`: Саша-ребёнок, Саша-взрослый, четыре друга в детстве и сейчас
- `src/components/`: полароид, караоке-субтитры, конфетти, карта, ночной Дубай, переходы
- `scripts/sync-audio.mjs`: копирует песню в `public/` и составляет список фото
